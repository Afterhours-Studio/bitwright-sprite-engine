# Feedback from the first real sprite (2026-10-21)

Sprite: "Idle Cultivation" / `sword-cultivator-idle`, 40x56, a chibi hero in
the Task Bar Hero style, drawn from an AI reference with fake pixels at
~18.6 px. Stopped at the silhouette gate.

## Packs

Runs after the packs in flight land (style B/C, MCP parity), because they
share `mcp/tools`, `reference.rs` and the guide.

**E. Style rules an agent can set, and chibi proportions** (Opus)
- `set_style_rules` over MCP (project style, with an optional per-asset
  override if the store supports it cheaply): validated, partial update,
  logged. `get_style_rules` already exists.
- A body-proportions choice for small chibi heroes (big head, raised small
  details) that widens the silhouette gates: `reads-at-1x` P^2/A band and the
  `solidity` ceiling. The measured case: P^2/A 43.6 against 18..28, solidity
  0.837 against 0.62..0.82, on a design whose raised two-finger seal, hair
  strand and hair tail are the point. Numbers justified in the plan note.
- Hue rotation is measured in HSL while lightness and chroma are OKLCH, and
  the guide does not say so. Measure in OKLCH hue, re-derive the threshold so
  the built-in ramps still pass, and state the space in the guide.

**F. Reference import that agrees with pixelize** (Sonnet)
- The import panel's conform step detected "31.35 x 22.39, 2% confidence"
  on an image `pixelize_reference` reads correctly as 18.597 px (31x48). Use
  the pixelize grid detector in the conform report.
- "Apply palette" fails the hue-shift rule on extracted ramps that only
  change lightness: repair the ramps (add the hue shift) and say so, or
  explain instead of failing.
- `pixelize_reference` writes full colour into `silhouette` and a 24-slot
  palette, which breaks the silhouette step and blocks `set_palette` with
  fewer slots. Write the one-slot mask into `silhouette` and the colour
  result into `flats` (or a reference layer), and only grow the palette when
  asked.
